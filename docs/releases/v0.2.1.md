# Continuum v0.2.1 - Issue Acceptance And Safety Hardening

`v0.2.1` completes a bounded set of release acceptance work on top of the
opt-in orchestration foundation.

## Highlights

- Added semantic memory refresh and retrieval with event attribution,
  task/recency ranking, exact-search fallback and bounded output.
- Added task worktree create, diff, gated merge and discard workflows.
- Added explicit Control Center actions for team editing, provider testing,
  workflow actions and compact resume context.
- Added native service definition support for Windows, macOS and Linux.
- Added an optional Docker Compose vector-service profile.

## Safety Fixes

- Worktree test and review approvals are pinned to the exact candidate commit.
- Control Center rejects unsafe team configuration filenames.

## Verification

- 64 unit tests passed locally.
- CI passed on Windows, macOS and Ubuntu with Python 3.9 and 3.13.
- npm package dry-run and JavaScript syntax validation passed.

## Boundaries

PTY-backed interactive wrappers, complete service lifecycle validation, public
npm/PyPI publication and a hosted demo recording remain separate work.
