# Continuum v0.2.0 - Opt-In Sequential Orchestration

`v0.2.0` introduces explicitly authorized, sequential agent workflows while
retaining Continuum's bounded-context memory model.

## Highlights

- Added Continuum Teams execution with bounded per-role context packets.
- Added stored workflow messages and MCP access for bounded collaboration.
- Added Ollama-ranked retrieval over stored embeddings with exact search as
  the default retrieval path.
- Added CLI agent invocation adapters.
- Made `continuum resume` inject a bounded handoff into the launched agent.
- Prevented model providers such as Ollama and OpenRouter from claiming files.
- Required explicit claimed paths and a clean unrelated workspace for writer
  roles.

## Boundary

Execution is opt-in and sequential. This version does not claim unattended
parallel orchestration.
