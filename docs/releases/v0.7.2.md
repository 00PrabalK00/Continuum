# Continuum v0.7.2

This patch improves model-provider usability from the CLI and interactive
shell.

## Added

- `model ask` accepts unquoted multi-word prompts:

```bash
continuum model ask ollama summarize this pasted text
```

- Provider failures now include exact recovery commands for:
  - Ollama API unavailable at `localhost:11434`
  - OpenRouter HTTP 401 unauthorized API keys
- `continuum shell` detects bracketed paste sequences, stores the full pasted
  content and shows a compact `{n chars}` receipt before dispatching.

## Notes

If `continuum --version` shows an older version than `python -m continuum
--version`, reinstall from the repo with `python -m pip install .`.
