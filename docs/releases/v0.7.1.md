# Continuum v0.7.1

This patch makes the interactive shell closer to the normal CLI surface.

## Added

- `/switch <claude|codex|gemini> [compact|normal|deep] [agent args]`
  selects an agent and dispatches `continuum resume` with the current project
  context injected.
- Exact CLI-style slash commands for known Continuum commands, including:

```text
/mcp serve
/adapters list
/context build coder --mode compact
/handoff --task "Fix auth" --next-step "Run tests"
/instruct --planner claude-opus-4-1-20250805 --executor codex --goal "Fix tests"
```

## Notes

The shell injects the active project and vault automatically unless the command
already includes `--project`.
