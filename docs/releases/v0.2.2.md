# Continuum v0.2.2 - Interactive CLI Surface

`v0.2.2` adds a terminal-first operator console over Continuum's existing
safe commands.

## Highlights

- Added `continuum shell` with slash-command navigation.
- Added color-coded agent targets and model providers.
- Added per-session `--color` and `--animation` options plus `/color` and
  `/motion` toggles.
- Added slash aliases for handoff/resume, memory, teams, tasks, worktrees,
  service control, MCP guidance and Control Center.

## Boundary

The console controls the existing wrapped-session runner. It does not claim
PTY/ConPTY terminal emulation, attachment to external sessions or automatic
parallel agent scheduling.
