# Continuum v0.1.0 - Alpha Baseline

`v0.1.0` establishes Continuum as local shared memory for coding agents.

## Highlights

- Added project-scoped SQLite events and bounded Markdown handoffs.
- Added `init`, `up`, `down`, `logs`, `handoff`, `run`, `resume`, `status`
  and `search` commands.
- Added the npm launcher front door for the host-local Python daemon.
- Added progressive MCP memory tools and controlled task/file claims.
- Added Ollama and OpenRouter model-provider configuration.
- Added JSON team presets and local Control Center state views.
- Added optional Obsidian mirroring and Windows sign-in startup installation.
