# Continuum v0.7.0

Release date: 2026-05-29

## Added

- `continuum instruct` for Hierarchical Model Delegation.
- Graph-backed delegation state stored under `.continuum/delegations/<id>/graph.json`.
- Compact markdown execution packets for executor agents.
- Slash command support for:

```text
/instruct planner=claude-opus-4-1-20250805 executor=codex mode=checkpoint goal="Implement deterministic PTY input receipt validation"
```

## Behavior

The planner role creates the contract. The executor role receives only the
bounded packet: goal, reason, allowed files, constraints, acceptance checks,
failure conditions and escalation triggers. Continuum stores the graph for
orchestration and communicates with models through compact markdown.
