# v0.3.0 - Live Interactive Terminal Foundation

## Added

- `continuum run --interactive <agent>` for terminal-native agent sessions.
- `continuum resume --interactive <agent> <mode>` for bounded context
  injection into a live agent terminal.
- `/terminal` and `/resume-terminal` commands in `continuum shell`.
- Native PTY execution on macOS/Linux and `pywinpty`-backed terminal
  execution on Windows.

## Behavior

Interactive sessions stream terminal output to the user while continuing to
record session logs, estimate checkpoint usage and write handoffs. The
captured-output `run` and `resume` behavior remains available for
non-interactive automation.

## Boundary

This release provides the cross-platform terminal layer. Dedicated parsing
and approval handling for each agent CLI, external-session attachment and
parallel scheduler automation remain separate work.
