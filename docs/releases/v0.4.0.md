# v0.4.0 - External Session Bridge

## Added

- `continuum session detect`, `attach`, `list`, `refresh`, `inject` and
  `detach` for supported Claude Code, Codex and Gemini CLI processes started
  outside Continuum.
- Automatic registration by the running daemon when a supported agent process
  starts inside the watched project.
- Persistent PID plus process-creation-time identity tracking, preventing a
  reused PID from becoming the wrong attached session.
- MCP tools for listing attached external sessions and reading their bounded
  continuation packets.

## Safety Boundary

An already-running CLI owns its existing terminal. Continuum publishes
bounded context and exposes MCP memory for that process; it does not
retroactively capture old terminal output or inject unaudited keystrokes into
an arbitrary terminal window.
