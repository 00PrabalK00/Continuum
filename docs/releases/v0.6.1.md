# v0.6.1 - PTY Input Receipt Acceptance

This patch strengthens the PTY/ConPTY acceptance suite.

## Added

- End-to-end input receipt test for the interactive terminal wrapper.
- The child process emits a structured receipt containing target id, cwd,
  process generation, prompt hash, input hash, PTY acceptance status,
  transcript observation and output advancement.

## Why

Lifecycle and output capture can pass even when an interactive prompt is
misclassified or bytes are delivered to the wrong state. The new acceptance
test requires the same live process to visibly advance after consuming the
expected input.
