# v0.6.0 - Parallel Worktree Scheduling

Continuum now prepares safe parallel development lanes across Git worktrees.

## Added

- `continuum worktree schedule` creates a schedule from one objective and
  multiple `role:agent:path1,path2` lanes.
- `continuum worktree schedules` lists planned parallel schedules.
- `continuum worktree schedule-status` reports lane status, dependencies,
  gates and merge readiness.
- `continuum worktree resume` launches an agent inside the task worktree while
  injecting shared root Continuum memory.
- Schedule context packets are written under `.continuum/worktree_context/`.

## Safety

- Overlapping lane file ownership is rejected before worktrees are created.
- Dependency lanes block merge until their dependency is merged or done.
- Existing worktree merge gates still apply: passing tests, approved review,
  no uncommitted worktree changes and no commits after recorded gates.
- Automatic parallel provider launching is not enabled in this release.

## Try It

```bash
continuum worktree schedule "Build auth flow with tests" \
  --lane backend:claude:src/auth \
  --lane tests:codex:tests \
  --depends-on tests:backend
continuum worktree resume T0001 claude compact
continuum worktree schedule-status P0001
```
