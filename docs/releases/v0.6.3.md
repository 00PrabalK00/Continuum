# Continuum v0.6.3

Release date: 2026-05-29

## Added

- Optional Docker image and Compose `ui` profile for running the Continuum
  Control Center against a mounted project directory.

## Fixed

- Docker image builds now copy `README.md` into `/app` before `pip install .`
  so setuptools can read the package metadata declared by `pyproject.toml`.

## Contributors

- Docker support by [o0ga-bo0ga](https://github.com/o0ga-bo0ga).

## Verification

- `python -m unittest discover -s tests -v`
- `python -m unittest discover -s examples\multi-agent-handoff -v`
- `python -m pip install .`
- `python -m continuum --version`
- `npm pack --dry-run`
