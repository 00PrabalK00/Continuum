# v0.5.0 - Interactive Agent Adapters

Continuum now has dedicated interactive terminal profiles for Claude Code,
Codex and Gemini CLI.

## Added

- `continuum adapters list` reports supported launched-terminal behavior.
- Interactive `run` and `resume` sessions persist the active adapter, visible
  terminal phase and explicit input or approval prompt counts.
- Codex interactive sessions default to the selected project with `-C`.
- Gemini resume sessions use its interactive prompt mode for bounded handoff
  injection; Claude receives an initial positional handoff prompt.

## Safety

Adapters observe explicit terminal prompts but do not approve actions or
enable permission-bypass modes. An externally launched agent session can
receive a cooperative Continuum context packet, but Continuum does not silently
control a terminal it did not start.

## Try It

```bash
continuum adapters list
continuum run --interactive codex
continuum resume --interactive gemini compact
```
