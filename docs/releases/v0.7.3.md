# v0.7.3 - Agent Chat Shell Dispatch

Continuum shell now treats plain text as a message to the selected agent instead
of rejecting it as a missing slash command.

## Added

- `continuum chat <agent> [compact|normal|deep] <message>` sends one message to
  Claude, Codex or Gemini with bounded Continuum context injected.
- `/chat [agent] [mode] <message>` is available inside `continuum shell`.
- Plain text inside the shell maps to `/chat <selected-agent> compact <message>`.

## Fixed

- Typing `hi` at `continuum[claude]>` now sends a compact-context message to
  Claude instead of printing the slash-command help text.

## Notes

Use `/resume-terminal <agent> <mode>` when you want the full live Claude, Codex
or Gemini terminal. Use `chat` for a one-shot context-injected message.
